# 燃灯夜行 · 夜渡

Windows 原生版 3.0.0，包含灯市旧巷、白狐渡、沉钟寺与无明塔四章连续冒险。解压后打开 `NightRoad.exe`，`NightRoad.pck` 须放在同一目录。运行不需要安装 Python 或 Godot，也不需要联网。

## 操作

| 动作 | 键鼠 | 手柄 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左摇杆 / 十字键 |
| 瞄准 | 鼠标 | 右摇杆，无输入时沿移动方向 |
| 普攻 | 左键，点按或长按 | RT |
| 主动技能 | 右键 / Q | RB（也支持 X） |
| 闪避 | 空格 | LT（也支持 A） |
| 交互、过门 | E | Y |
| 祭灯引导 | 长按 E | 长按 Y |
| 行囊 | B | View |
| 地图 | Tab | LB |
| 暂停 | Esc | Start |
| 奖励选择 | 鼠标 / 数字键 | 方向选择后按 A |
| 刷新成长候选 | R | 选择刷新按钮 |
| 全屏 | F11 | 设置页 |

闪避有两次充能，通常每三秒恢复一次。闪避有短暂无敌，可取消攻击起手，不能穿墙。芦苇草履增加闪避速度与距离，不延长无敌时间。

## 四章探索

每章十四间相连房间，四章共五十六间。主路连接四间普通战斗房、休息处与首领；支路位置随种子变化，包含装备、技能、商店、奇遇、祭灯与精英房。另有隐藏房。清房后自动收取铜钱，再选择一次强化。

门框路签标明目的地。靠近门查看收益，按 E 过门。安全房间在中央道具旁交互。Tab 地图显示当前房间与已知路线；清房后可快速返回已访问的安全房间。每章累计击败三十五名敌人后揭示隐藏房；夜行舆图可提前揭示。

| 章节 | 环境与首领 |
| --- | --- |
| 灯市旧巷 | 百目灯魁受灯柱保护。击破灯柱可削弱它，半血后会重新点灯。 |
| 白狐渡 | 水纹区域定期涨潮，先出现预警再爆发。渡月狐姬锁定方向后突进，每第三次攻击发射环形弹幕并召狐。 |
| 沉钟寺 | 钟声在玩家当前位置留下延迟落点。沉钟守将轮流使用三段重砸、环形弹幕与大范围落钟。 |
| 无明塔 | 两侧封印轮流爆发。无明塔主交替使用环形弹幕、延迟符阵、扇形射击和召唤；生命低于三分之一后部分招式加强。 |

首领半血后狂暴。控制技能与重击积累失衡，失衡时可以集中输出。前三章首领死亡后选择章间战利品，再进入下一章；装备、技能、符印、遗物、铜钱与属性全部保留。只有击败无明塔主才算整局胜利。

## 构筑

同时携带一件装备、一个主动技能、最多六种符印与六件遗物。基础属性独立生效。装备与技能最高三阶，二阶选择一种改造；更换时保留阶数并重新选择改造。符印最高三级，满槽可以替换。

六件装备：朱砂符匣、桃木剑、毒针筒、伏魔槌、雷纹轮、寒砂壶。六种技能：镇魂印、毒雾符、影分符、缚地咒、爆焰丸、霜环。共有十六种符印、十六件遗物。

- 回身斩与灵狐尖牙增强闪避后的首次普攻，可搭配桃木剑或伏魔槌。
- 火与毒触发燃瘴，火与霜触发融霜，雷与水或霜触发引雷。反应伤害不会无限递归。
- 碎寒提高对减速、眩晕目标的伤害，残钟铜片更容易使首领失衡。
- 凝神增强主动技能伤害，包括影分符残影；狐纹铜镜增加一道残影。残影不会重复触发普攻符印。
- 长锋增加近战范围和普攻射程，穿云增加投射普攻穿透，桃木剑的剑气也能受益。
- 旧砚让新获得的符印直接达到二级；已有符印仍每次提升一级。
- 封塔铜钥提高首领伤害，同时降低对其他敌人的伤害；余烬面具增强半血以下的火伤。

## 奇遇与支路

第一章从四种奇遇中抽选，后三章各有两种专属奇遇。每章出现一间奇遇房，每次只能选择一个分支。

白狐渡可用生命换草履、用最大生命换狐镜，或购买折扣铜钱与刷新次数。沉钟寺可购买残钟铜片、用额外精英换刷新、用最大生命换旧砚，或重选二阶以上技能改造。无明塔可承担额外精英换铜钱、购买封塔铜钥，或付出生命与下一间战斗的风险取得余烬面具。

所有成本在选择前显示。无法支付、已持有指定遗物或受禁疗限制的选项会禁用。遗物满槽后进入替换选择。商店折扣仅作用于商店，奇遇价格不打折。

祭灯需要完成两次引导与两波敌潮，成功后选择遗物；精英房同样提供遗物。商店各项商品每章限购一次。休息处可选择回复或装备升阶。

## 角色、挑战与保存

提灯人初始火符与镇魂印，清房获得护盾；听雨初始剑与缚地咒，闪避充能更快；葛翁初始毒针与爆焰丸，擅长火毒持续伤害，清房回血。

支持四档难度、三种契约、三道誓愿与营地成长。禁疗封印普通回复，不灭灯芯的复活仍可生效。每日挑战固定当天种子、提灯人、难度一与无契约，并关闭营地属性；榜单是本机记录。

局内每十二秒自动保存，暂停菜单可保存退出。地图、敌群、构筑、随机状态、章间战利品和待选奖励均保存。3.0 可继续有效的 2.0 第一章局内存档，完成第一章后进入后续章节；旧自动符术版的局内存档不属于这一规则。营地进度保留。

存档位于 Godot 用户数据目录，营地为 `profile.json`，对局为 `expedition.save`，备份后缀为 `.bak`。设置页支持导入旧营地，并提供音量、震屏、粒子和全屏选项。关闭粒子后，敌箭、危险弹道和落点预警仍然可见。
