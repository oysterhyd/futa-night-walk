# 第一章验收记录

版本 2.0.0，验收日期 2026-10-15。交付内容为「灯市旧巷」完整一章：从角色与誓愿选择、街巷探索、局内构筑，到百目灯魁、结算、营地和下一局。第二章以后的动作玩法不在本次交付范围。

## 已交付内容

- 三位角色；手动瞄准与攻击、两次充能闪避、一个主动技能。支持键鼠与手柄按钮/摇杆映射。
- 十四个相连房间，主路固定、支路位置与房间布局随机。包含有限敌潮、装备、技能、商店、四种奇遇、祭灯、精英、休息和隐藏房间；支持过门、探索地图与安全节点返回。
- 六件装备、六种技能，各有三阶和两个改造方向，共二十四条改造路径。装备和技能各占一个槽位，更换时保留阶数。
- 十二种符印、八件遗物、四种基础属性成长；符印与遗物各限六种。包含触发效果、替换选择、火毒/火霜/冰雷反应、誓愿、难度、契约与每日挑战。
- 首领具有可破坏灯柱、减伤、落火预警、环形与瞄准弹幕、召唤敌群、半血狂暴和失衡窗口。
- 保留原有木版画、剪纸、墨蓝/纸白/朱红配色与刻版控件。新增灯市道具、地面和装备/技能图标；接入镜头、刀弧、纸屑、受击、状态反应、屏外危险标记与声音反馈。
- 局内自动保存、暂停保存、备份恢复、构筑记录与营地继承。旧版局内存档与新规则不同，不能直接续为动作对局；旧营地进度保留。

具体操作、成长规则与组合见 [游玩说明](CHAPTER_ONE_GUIDE.md)。

## 性能与发行

性能结果以最新 [performance.json](../godot/test-output/performance.json) 为准。负载是人为保持高生命的 170 个敌人与至少 400 枚弹道，满符印/遗物、手动装备与影分技能，同时执行自动存档。先预热两秒，再采样三十秒；1600×900，关闭垂直同步，NVIDIA GeForce RTX 4060 Laptop GPU。它验证密集负载下的帧时间，不代表所有电脑都能达到相同帧率。

本次最终采样为 2531 帧：平均 84.35 FPS，平均帧时间 11.86 ms，p95 为 12.96 ms，p99 为 14.58 ms。平均敌人数 170，平均弹道数 400.24；自动存档失败零次。

新美术通过内置生图工具制作。原图文件名、完整提示词、透明选项和工程用途见 [素材记录](../godot/assets/ART_RECORD.md) 与 [提示词记录](../godot/assets/data/chapter_art_record.json)，发行包附相同记录及 Godot、字体和项目许可。图集测量工具只记录轮廓位置，没有修改图片像素。

## 尚未验证的体验

没有实体手柄和真人新手试玩结果；手柄检查使用 Godot 原生模拟按钮与轴事件。自动化通关可以验证可达性与规则，但不能替代玩家对难度、打击感、教程和长期平衡的评价。低配置电脑、其他 Windows 版本及不同屏幕缩放未进行实机矩阵测试。
