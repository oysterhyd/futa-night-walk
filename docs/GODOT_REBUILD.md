# 符塔夜行 · 原生引擎重构

目标：交付完整的 Godot 单机游戏，全面提高画面、动作、反馈、玩法深度与可维护性。Windows 1.0.0 可执行包已生成，以下九项原生版验收通过，证据见 `NATIVE_QA.md`。用户手动执行了旧版主体清理，原生版清理后重新导入与规则检查通过；剩余旧素材导入缓存的删除被环境拦截。

## 产品实现

原生工程在 `godot/`，使用 Godot 4.7.2 标准版与 GDScript。运行游戏不依赖 Python。原有四关、三位角色、二十种符术、六条进化、十二种行装、十二件旧物、营地成长、四档难度、契约、每日同途与循环长夜全部进入原生版。

用户明确选择民俗木版画与剪纸，并要求字体、菜单控件整体风格化。当前使用墨蓝、纸白、朱红，正文为文楷、标题为毛笔字，独立排字与刻痕，按钮为路签，选卡为符纸，面板为书页，标识为朱印。角色、五类怪物、四位首领、四处场景与环境道具均使用新版印画资产。

新增三道誓愿、元素状态联动、首领怒相与真实蓄力、弓手锁定箭路、石卫震击、可暂停蓄力的震慑、四槽旧物选择与替换。各类投射符术有不同刻版形状，影分身使用角色残影。四处场景、渡口与首领使用六段原创立体声循环，切换时淡入淡出，关键提示保留独立声部。

局内记录安全序列化，保持 RNG 与数值精度；损坏主记录回退有效备份，替换前归档损坏原文件。营地购买与结算写入失败回滚，奖励去重。设置支持旧版营地合并导入，原文件保持不变。最近足迹与本机最佳成绩可以翻阅。

## 架构

- `core/content_db.gd`：内容、印画资源与共享动作缓存。
- `core/save_store.gd`：存档、备份、迁移、结算与本机记录。
- `core/audio_director.gd`：章节状态、双声部音乐切换和提示优先级。
- `systems/run_world.gd`：固定步长、空间索引、战斗成长、关卡与可恢复状态。
- `presentation/`：原生动作、图集脚底对齐、批量投射物、反馈与场景。
- `ui/`：刻版控件、字体、册页、朱印与手记。
- `tests/`：规则、自然模拟游玩、原生输入、实际动作时钟、视觉与密集场景性能。

## 验证入口

从仓库根目录，用 PowerShell 7 运行：

```powershell
pwsh -NoProfile -File tools/verify_native.ps1
pwsh -NoProfile -File tools/build_native_release.ps1 -Version 1.0.0
```

报告和截图写入 `godot/test-output/`。测试使用各自的独立用户存档目录。GUI 检查使用实际 Godot 窗口和渲染器，输入脚本注入键盘、鼠标及设备 0、1 的标准手柄事件，不声称已经现场测试实物控制器。自然模拟游玩不替代真人体验；压力负载使用高生命怪物持续维持密集场景。

最终结果、硬件、范围与发行包启动证据集中记录在 `docs/NATIVE_QA.md`，以实际文件和日志为准。

## 开发环境

引擎为 `$env:LOCALAPPDATA/FutaGameTools/Godot-4.7.2-stable/Godot_v4.7.2-stable_win64_console.exe`。Windows 官方模板在用户 Godot 导出模板目录。

字体源位于 `tools/_sources/LXGWWenKai-Medium-source.ttf` 与 `MaShanZheng-source.ttf`，来源与 OFL 见素材记录。新增中文后运行 `python tools/bundle_godot_fonts.py` 并重新导入工程。游戏运行与普通发行导出不需要 Python。

Git 工作区原本已有用户修改与删除，不能重置；安全目录例外使用单次命令，不修改全局 Git 配置。
