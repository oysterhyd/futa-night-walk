# 燃灯夜行 · 夜渡

Windows 原生版 2.0.0。当前可游玩内容为第一章「灯市旧巷」。解压发行包，打开 `NightRoad.exe`；`NightRoad.pck` 必须和它放在同一目录。运行不需要 Python、Godot 或网络。

## 操作

| 动作 | 键鼠 | 手柄 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左摇杆 / 十字键 |
| 瞄准 | 鼠标 | 右摇杆；无输入时沿移动方向 |
| 普攻 | 左键，点按或长按 | RT |
| 主动技能 | 右键 / Q | RB（也支持 X） |
| 闪避 | 空格 | LT（也支持 A） |
| 交互与过门 | E | Y |
| 祭灯引导 | 长按 E | 长按 Y |
| 行囊 | B | View |
| 地图 | Tab | LB |
| 暂停 | Esc | Start |
| 选择奖励 | 数字 1–9 / 鼠标 | 方向选择后按 A |
| 刷新成长候选 | R | 选择刷新按钮 |
| 全屏 | F11 | 设置页 |

闪避有两次充能，通常每 3 秒恢复一次。闪避期间短暂无敌，可以取消攻击起手；不能穿墙。听雨充能更快。

## 第一章路线

地图每局生成十四个相连房间。四间普通战斗房位于主路，其他房间的位置会变化。进战斗房后封门，清掉有限敌潮后开门。清房自动收取铜钱，只提供一次主要成长选择。

靠近门按 E 进入相邻房间。靠近安全房间中央的道具按 E 交互。地图显示已探索房间和相邻房间；清房后可通过地图快速返回已访问的安全节点。

- **兵器铺**：从候选装备中更换一件，或保持原装备。
- **废亭符谱**：更换唯一主动技能。
- **夜市货郎**：花铜钱买回复、装备升阶、技能升阶或遗物，每项限购一次。
- **祭灯台**：长按点灯，抵挡两波敌潮，成功后选取遗物。
- **血契院**：击败带额外属性的精英及敌群，选取遗物。
- **巷中奇遇**：四种事件随机出现，选择前会说明具体收益和代价。
- **古道茶摊**：回复 50% 最大生命，或将装备升一阶。
- **封门小巷**：击败 35 名敌人后揭示；夜行舆图可提前发现。
- **百灯院**：击败百目灯魁，完成第一章。

灯魁身边的灯柱存活时，灯魁受到的伤害减少 30%，部分招式也更密集。击破灯柱会额外伤害灯魁。半血后进入狂暴，重新点燃灯柱。控制技能与重击可以积累失衡，制造短暂输出窗口。

## 装备、技能与构筑

同时只携带一件装备、一个主动技能。普通攻击需要玩家发动，影分符也需要玩家攻击才会输出。

装备包括朱砂符匣、桃木剑、毒针筒、伏魔槌、雷纹轮与寒砂壶。技能包括镇魂印、毒雾符、影分符、缚地咒、爆焰丸与霜环。

装备与技能最高三阶。本体伤害倍率依次为 1.0 / 1.2 / 1.4。二阶从两个改造方向中选一个，三阶继续强化该方向。换装备或技能会保留阶数，并重新选择新物品的改造。更换技能会结束旧技能的残留输出。

符印最多六种，每种最高三级；遗物最多六件，不重复。满槽后可以替换。基础属性不占这些槽位。成长候选至少包含一项通用属性和一项适配当前配置的符印。

可尝试的组合：

- 火符或爆焰丸配合毒雾，先上状态，再主动引爆。
- 桃木剑配合回身斩与灵狐尖牙，闪避换位置后反击。
- 寒砂或霜环配合雷纹轮，减速敌群后传导雷击。
- 伏魔槌配合缚地咒，聚怪、打断并抓住失衡窗口。
- 普攻配合影分符，在技能持续期间集中攻击；残影不重复触发普攻符印。

火 + 毒触发燃瘴，火 + 霜触发融霜，雷 + 水 / 霜触发引雷。追加反应不会再次无限触发同类反应。重复施加状态会刷新持续时间，当前较强的持续伤害在状态结束前保留。

## 角色与挑战

- **提灯人**：初始火符与镇魂印。清房获得 8 点护盾，适合初次游玩。
- **听雨**：初始桃木剑与缚地咒。闪避后的首次普攻伤害 +15%，闪避恢复更快。
- **葛翁**：初始毒针与爆焰丸。火毒持续伤害 +60%，清房回复 6 点生命。

可选择三道誓愿，也可不立誓。四档难度和三种契约用于提高挑战。禁疗契约会封印普通生命回复；不灭灯芯的复活仍可生效。

每日挑战使用当天固定种子，固定提灯人、难度一与无契约，关闭营地属性加成。榜单为本机记录。

营地天赋共八级：每级增加 3 点初始生命、2% 伤害、1.5% 移速，或一次刷新机会。旧营地进度保留；旧自动符术对局与新版动作对局采用不同规则，旧局内存档不能直接继续为新版对局。

## 保存与设置

每十二秒自动保存局内状态。暂停菜单可保存并退出，关闭窗口也会保存。存档包含地图、敌群、随机状态、装备、技能、符印和待选奖励。

存档位于 Godot 的用户数据目录，营地文件为 `profile.json`，局内文件为 `expedition.save`。备份后缀为 `.bak`；主文件损坏时尝试读取有效备份。设置页支持导入旧版营地存档，并提供音量、震屏、粒子和全屏选项。
