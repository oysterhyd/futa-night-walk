# 燃灯夜行 · 夜渡

长夜漫漫，百鬼横行。持辟邪古灯破夜诛邪，穿巷渡江，直登古塔之巅。

这是 Windows 64 位原生版。解压整个发行包，打开 `NightRoad.exe`；游戏数据 `NightRoad.pck` 与可执行文件放在同一目录。运行游戏不需要安装 Python 或 Godot。发行包在 Windows 11 上验证。

## 提灯入夜

符术自动施放，你负责走位、闪避、镇魂与点灯。每局先立一道誓愿，再逐步组合四种符术、六种秘卷与四件遗物。三位夜行者拥有不同的初始属性与特性，击败首领会解锁后续角色。

| 操作 | 键鼠 | 手柄（Xbox 键位） |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左摇杆 / 十字键 |
| 闪避 | 空格 | A |
| 镇魂 | Q / 鼠标右键 | X |
| 激活神灯 | 靠近后长按 E | 靠近后长按 Y |
| 行囊与进阶配方 | B | View |
| 暂停 | Esc | Start |
| 菜单确认 / 返回 | Enter / Esc | A / B |

摇杆可以轻推慢行。游戏会随最近使用的设备实时切换战斗按键提示。

## 构筑与强化

- **烬火誓**：火符伤害大幅提升，触发【燃瘴】回复生命与镇魂充能，代价是降低生命上限。
- **渡月誓**：冰霜与雷电擅长控场减速，闪避冷却更短，代价是其他元素伤害略降。
- **百符誓**：弹道符术额外追加发射一枚，击败敌人还能增加刷新次数，代价是单发符弹伤害稍低。

二十种符术最高可升至 5 级，十二种秘卷最高可升至 3 级。当符术升满 5 级并持有对应秘卷时，即可触发【符法蜕变】进阶进化。遗物最多同时携带 4 件，槽位满后可进行替换，或将新遗物折算为铜钱。

火与霜触发【融霜】增伤，火与毒触发【燃瘴】范围爆炸，雷遇霜或水触发【引雷】传导麻痹。镇魂绝技充能完毕后释放，可大范围击退敌群并清除全屏弹幕。朱红预警圈提示高危招式：弓手锁定箭路、狐妖直线冲刺、石卫与首领蓄力重砸。

## 游戏模式

**主线闯关**：顺次探索灯市旧巷、白狐渡、沉钟寺与无明塔。守住每波敌潮并击败关底首领，挑选前行路线与奇遇。

**无尽长夜**：击败第四位首领后继续深入，敌群属性持续提升，挑战极限生存关数。

**每日挑战**：按每日固定种子生成，统一使用提灯人、难度一且无额外契约，不生效营地加成，公平竞速与生存比拼。

四档难度与三项额外负面契约可自由搭配挑战极限。选择「枯泉禁疗」契约将彻底封印生命回复，极度考验走位操作。

## 营地与手记

战斗结算获得的灯烬可用于渡口营地强化永久天赋（生命、伤害、移速、刷新机会）。夜行手记完整收录个人成就、历史战绩与挑战榜单。

## 保存与存档管理

游戏每十二秒自动暂存局内进度。暂停菜单点击“保存并退出”或关闭窗口均会妥善保存。

存档存储于系统应用数据目录。营地存档为 `profile.json`，对局记录为 `expedition.save`，并配备完整自动备份。设置页支持导入旧版营地存档并安全合并进度。
