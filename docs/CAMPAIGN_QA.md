# 3.0.0 四章动作版验证记录

本记录区分规则检查、完整机器人冒险、原生界面与动画、渲染压力测试及发行包检查。自动化结果不代表真人难度评价或实物手柄验收。

最终回归完成于 2026-10-15 06:19 UTC，十一组全部通过；发行包随后完成仓库外启动与哈希检查。引擎为 Godot 4.7.2 stable。

## 内容与规则

- `chapter-tests.json`：160 项基础动作、装备、技能、成长、碰撞与存档检查。
- `chapter-modes.json`：42 项第一章每日、契约、四种旧奇遇全部分支与备份恢复检查。
- `campaign-tests.json`：83 项四章生命周期、独立首领攻击、环境预警、构筑跨章、旧第一章存档迁移、原子恢复失败与唯一结算检查。
- `campaign-content-tests.json`：202 项新增章节奇遇、遗物、符印与模式检查。六种奇遇的三个分支全部覆盖，核对实际成本、指定遗物、满槽替换、重复领取、待选存档和禁疗。还检查四章每日相同输入的确定性、敌潮契约与四档难度下的首领招式。

当前内容为四章各十四间房、三角色、六件装备、六种技能、十六种符印、十六件遗物、十种奇遇。前三章首领死亡后进入章间奖励，第四章首领死亡后完成整局。

## 完整冒险

`campaign-playtest.json` 包含提灯人、听雨、葛翁各两个种子，共六次四章完整冒险。各次均击败四名首领、完成四次祭灯并访问五十二间房。使用正常生命、伤害与营地关闭条件，通过移动、手动攻击、技能、闪避、交互和奖励选择推进。

机器人控制器可以读取敌人、危险区域与地形，且按固定探索路线行动。这证明所测组合可以走完整局，不证明所有构筑都能通关，也不用于估计真人通关率。另保留六次第一章完整机器人冒险作为基线。

## 原生界面、动画与画面

- `chapter-flow.json`：26 项原生输入与界面检查，包含键鼠、模拟手柄按钮及轴、第一章进入第二章、跨章音乐、最终胜利与记录。没有接入实物手柄。
- `chapter-animation.json`：真实渲染时钟下的行走、闪避、施法、四名首领蓄力与攻击、狂暴、死亡到结算。首领场景通过状态夹具建立。
- `chapter-visual.json`：34 张界面截图，覆盖卡片、行囊、地图、存档、设置和结算等。
- `campaign-quality.json`：42 张战斗与内容截图，覆盖六件装备、六种技能、爆焰丸真实落地爆发、敌箭开关粒子与飞行、四章场景与门框路签、后三章施法／预警／爆发，以及六种新奇遇卡片。

画面复核关注危险轮廓、实际落点、角色辨认、文字溢出与门名位置。水纹、飞散符纸及碎片使用 MultiMesh 与项目内着色器批量绘制。预警轮廓和敌弹不依赖粒子开关。技能范围取自实际改造值，爆焰丸及连爆在真实延迟到期时产生爆发。

`audio-check.json` 对二十种战斗音效检查 PCM 峰值、RMS 和时长，最大峰值为 0.885，未发现削波。声音有独立声部、触发限流和重要提示优先级；此项属于技术检查，不代替主观听感测试。

## 性能与发行

`performance.json` 使用四章场景轮换，在 1600×900 原生窗口、关闭垂直同步的条件下测量；负载为一百七十名高生命敌人、四百枚敌弹、十四处持续循环的危险落点、完整构筑与自动保存。该负载是压力场景，不是正常游玩平均值。

测试硬件为 NVIDIA GeForce RTX 4060 Laptop GPU，正式采样三十秒、2936 帧。整体平均 97.84 FPS，P95 为 11.67 毫秒，P99 为 13.33 毫秒；四章各自 P95 为 11.67 / 11.43 / 13.33 / 11.11 毫秒。平均绘制调用约 278，自动保存无失败。未据此宣称低端硬件或所有分辨率均达到相同帧率。

铜钱与战斗碎片、符纸、水纹使用批量绘制；角色仅在状态变化时更新对应着色参数。前一轮曾出现慢帧超标，修正后独立压力复测与完整回归中的压力测试均通过。

完整入口为 `pwsh -NoProfile -File tools/verify_native.ps1`，报告在 `godot/test-output/`。发行由 `build_native_release.ps1 -Version 3.0.0` 生成，`verify_native_release.ps1 -Version 3.0.0` 将 EXE/PCK 复制到仓库外、限制 PATH 后启动菜单与战斗入口，并核验清单及压缩包中的文件哈希。

发行启动检查证明包可独立启动；完整冒险验证运行于相同源代码的 Godot 工程，未声称在导出的 EXE 中自动重走六次完整冒险。版本 2.0.0 与对应历史文档保留。
