# 游戏文案规范与去 AI 腔指南 (Text Style & Tone Guide)

> **适用范围**：面向后续接手此项目的开发 Agent 与策划，规范游戏内所有界面的命名、引导词、技能描述、世界观文案等，杜绝“AI味浓、强行抒情、堆砌辞藻、晦涩难懂”的问题。

---

## 一、本次文案重构背景与核心改动

此前游戏文案由大语言模型直接生成，存在大量**假大空、强行文青抒情、概念模糊、不知所云**的典型“AI腔”。本次优化在**完全不改动底层逻辑与数值机制**的前提下，对全游戏文本进行了系统性重写。

### 1. 游戏命名更新
* **原名称**：《符塔夜行 · 夜渡》 / 英文项目名 NightRoad
* **新名称**：《燃灯夜行 · 夜渡》
* **改名原因**：
  * 原名称“符塔”念起来生硬拗口，玩家难以在第一时间建立直观意象；
  * 新名称“燃灯夜行”完美契合游戏核心视觉（辟邪古灯、剪纸版画风、祭灯交互、灯烬代币），四字节奏朗朗上口，保留国风神秘感的同时通俗易记。

| 错误类别 | 典型原版文本（反面教材） | 为什么这是“AI味 / 坏文本”？ | 优化后标准写法 |
| :--- | :--- | :--- | :--- |
| **强行抒情 / 空洞网抑云** | *“提一盏灯，穿过灯市、狐渡与古寺。灯不灭，路就还在。”* | AI 极喜欢写这种虚无缥缈的排比鸡汤，看似高深实则信息量为零，缺乏游戏动作感与代入感。 | **“长夜漫漫，百鬼横行。持辟邪古灯破夜诛邪，穿巷渡江，直登古塔之巅。”** |

| **造作玄虚 / 误导机制** | *“借灯修习”* / *“夜路在此分岔”* | 过于追求“古风文雅”，导致玩家看不懂这是“技能升级三选一”还是“走格子选路线”。 | **“研习道法 · 技能升级”** / **“前路分岔 · 抉择路线”** |
| **晦涩行话 / 故弄玄虚** | *“修为 4阶”* / *“怒相”* / *“行装”* / *“旧物”* | 强行给通用游戏概念套生僻词。阶是等级还是关卡？怒相是状态还是名称？容易造成认知负荷。 | **“等级 4级”** / **“狂暴”** / **“秘卷（被动强化）”** / **“遗物（常驻增益）”** |
| **语义不通 / 偷懒敷衍的技能描述** | *“火符飞向最近敌人，命中后留下灼烧。”* / *“重针直击最近敌人，击退并使其停顿。”* | 机械翻译感严重，句式单一死板，缺乏动作打击感和细节反馈描述。 | **“掷出飞火符，命中时造成直接伤害并附带持续灼烧。”** / **“发射重型破甲长针，击中敌人造成强力击退与短暂僵直。”** |
| **故作高深的短句断句** | *“借一夜，还一剑。”* / *“雨停了，寺没了，剑还在里面。”* | AI 写故事时最廉价的“短句装逼”，三句话里有两个无病呻吟的排比，人物形象单薄虚浮。 | **“雨落剑出，断祟分明。”** / **“多年前在荒废古刹中遗落了佩剑。如今古寺已被妖雾侵蚀，她此行只为拔剑荡魔，取回旧兵。”** |

## 三、后续 Agent 必须遵守的“去AI腔”文案铁律

在为本项目或同类国风/肉鸽游戏撰写文本时，请严格对照以下 5 条铁律：

### 铁律 1：严禁“网抑云”式空洞抒情，确保“名词接地气，动词有力量”
* ❌ 严禁出现诸如“这一夜的心事……”、“路不灭，光就在……”、“把余温留给……”等莫名其妙的感性散文。
* ✔️ 动作肉鸽文案必须具备**目标感、危机感与爽快感**，多用实体名词（古灯、符箓、妖鬼、剑气、桃木）与精准动词（破夜、斩妖、迸发、贯穿、洗净）。

### 铁律 2：功能引导第一，氛围修饰第二
* 界面按钮、系统提示、功能面板的首要目标是让玩家**一秒看懂怎么操作、能获得什么收益**。
* ❌ 避免用生僻文艺词替换标准游戏术语：不要用“行装”代替“被动技能”，不要用“借灯”代替“升级”，不要用“同途簿”让人不知道这是“挑战榜单”。
* ✔️ 正确做法：标题可以用风格化词，但**副标题或说明必须说人话**。例如：`“研习道法 · 技能升级”`，既有道家风味，又有清晰的功能指引。

### 铁律 3：数值机制与收益效果必须精确交代
* 肉鸽玩家极其关注“效果是什么”、“代价是什么”。
* ❌ 模糊写法：“雷光传遍敌群”、“变得更加灵活”、“造成可观伤害”。
* ✔️ 精准写法：“额外连续跳跃四次电击敌群”、“弹道转弯速度与追踪角度大幅提升”、“全伤害提升 35%”。

### 铁律 4：技能描述要具备画面感与打击感
* 描述技能时，遵循【施法动作】+【弹道轨迹】+【命中反馈】的清晰结构：
  * **起手**：掷出 / 降下 / 射出 / 汇聚 / 召唤
  * **轨迹**：直线穿透 / 旋转盘旋 / 扇形喷吐 / 连锁弹跳
  * **反馈**：范围爆燃 / 强力击退 / 麻痹定身 / 撕裂敌群

### 铁律 5：修改文本时必须同步工程与资产依赖
* 本游戏底层基于 Godot 4.7 引擎，使用了中文字体子集裁剪工具（`tools/bundle_godot_fonts.py`）以及自动化集成测试脚本（`tools/verify_native.ps1`）。
* 在修改游戏内文本、按钮文本或配置数据后，**必须做到三步校验**：
  1. 检查测试脚本是否有硬编码匹配按钮或文本；
  2. 运行 `python tools/bundle_godot_fonts.py` 重新生成中文字体子集，确保没有缺失字形；
  3. 运行 `pwsh tools/verify_native.ps1` 确保所有 7 项原生测试全绿通过。

* **提灯人（原守灯人）**：
  * 称号：*灯在人在，破夜前行。*
  * 背景故事：*野渡口的守灯铜灯，孤悬亮了整整十三载。今夜阴风骤起，唯有孤身直入古塔，换下将尽的灯芯。*

  * 背景故事：*多年前在荒废古刹中遗落了佩剑。如今古寺已被妖雾侵蚀，她此行只为拔剑荡魔，取回旧兵。*
