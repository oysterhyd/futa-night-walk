# 民俗木版画 + 剪纸

用户明确选择的新方向，替换此前软光手绘与金边深色卡片。

## 统一规则

- 主色：墨蓝 `#183544`、纸白 `#e8dfc5`、朱红 `#ad3527`。
- 附属色仅用于玩法区分：霜蓝、草绿、土黄；避免虹彩、发光描边与电影式照明。
- 角色与怪物：厚而不均匀的刻线、明确剪纸轮廓、大块平涂、少量白色刻痕。100–180 像素显示时仍须清楚。
- 场景：低对比的版画地面、浓墨边缘造景、纸面留白；危险预警用朱红，友方符术用对应克制的印色。
- UI：符纸、路引、书页、印章。避免重复的圆角金框卡片、透明玻璃与大面积光晕。
- 字体：马善政毛笔标题与霞鹜文楷 Medium 正文；标题独立排字，控件使用刻版路签与朱印，深墨文字印在纸白上。
- 清晰度：默认窗口 1600×900，最低 1280×720；角色显示位置对齐像素，减少插值与低对比的小字。

## 素材迁移

新版位图使用 `*-print.png`，正式运行只使用当前选定的印画资产。角色图集保留动作对应，通过区域测量与脚底对齐避免串帧；施术使用单独的六帧图集。引擎直接加载新版，运行素材迁移已完成。旧版源素材已删除，仅开发导入缓存的清理尚未完成。

## 验收

必须查看实际游戏截图与动画；提示词、调色板或单张概念图不能证明风格统一。战场、菜单、选卡、行囊与首领均需检查。性能优化保留轮廓、动画和反馈，不以降低内容密度代替优化。
