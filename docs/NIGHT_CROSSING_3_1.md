# 3.1.0 改动记录 · 夜渡

3.1 在 3.0 四章战役的基础上重做界面与表现，补上故事，并加深战斗与构筑。存档向下兼容：3.0 的营地与局内存档可直接读取。

## 界面与美术

- 整体改为「漆夜」配色：深青漆底、黄铜描边、朱红强调色、纸纹颗粒。共用组件集中在 `ui/ui_kit.gd`，装饰线与菱形纹在 `ui/ornament.gd`。
- 按钮分为主按钮、次按钮、菜单项、页签四种，悬停时有毛笔扫过的动画；面板为切角漆盒，带黄铜角饰。
- 主菜单使用夜景插画作背景，带雾气、余烬粒子和缓慢推镜；页面切换用水墨晕染转场（`shaders/ink_wipe.gdshader`）。
- 战斗 HUD 重做（`ui/hud_view.gd`）：头像外圈显示灯焰，生命条带受击残影，护盾、闪避充能、技能冷却表盘、四象共鸣标记、首领血条。
- 设置页按「声音 / 画面 / 操作 / 存档」分组，新增「动态效果」「伤害数字」开关，对局中可从暂停菜单打开。行囊改为三栏：装备与技能、属性表、符印遗物与四象共鸣。
- 新增 7 张故事插画（`assets/images/story/`），用于主菜单、序章、章节标题卡和结局。

## 打击感与特效

- 顿帧、慢放、闪白与去色（`presentation/arena_view.gd`）：暴击、精英与首领死亡有短顿帧，识破触发慢放。
- 修复原先不生效的震屏，改为镜头偏移；鼠标瞄准时镜头向前探。
- 冲刺残影、燃灯光环、精英词缀标签，伤害数字改为描边弹出字。
- 夜色光照（`shaders/grade.gdshader`）：场景整体压成月光青灰，由玩家提灯、敌方预警、首领、敌弹、己方法术和祭灯等最多 32 个光源重新照亮；清房后天色转亮，燃灯时最亮。

## 玩法

- **灯焰与燃灯**：击杀、命中和识破积累灯焰，满后按 F / R3 释放角色专属大招（百灯照夜、一苇渡江、九转丹炉）。
- **识破**：闪避后 0.3 秒内躲开的攻击触发识破，慢放并给予灯焰、无敌和一次必定暴击、额外 1.5 倍伤害的普攻。
- **四象灯**：十六种符印分属朱雀、白虎、玄武、青龙，持有同一象 2 / 4 种激活一阶 / 二阶共鸣，给构筑一个明确方向。
- **精英词缀**：迅捷、铁甲、分魂、余火。

## 故事

- 世界观与文案集中在 `content/lore.gd`：渡口镇的冬至夜、无明塔的长明灯、三位主角的来历与动机、四位首领的称号与台词、结局。
- 首次开始战役播放序章；每章开头有标题卡，首领登场有黑边介绍卡；通关后播放结局。均可跳过。
- 夜行手记新增「见闻」页，随进度解锁人物、地点和首领条目，可重温序章。营地改为沈婆的渡口茶摊，台词随夜数变化。
- 文案遵循 `docs/TEXT_STYLE_GUIDE.md`：少抒情，多写具体的人和事；机制说明直接写数值。

## 验证

在 Linux（Xvfb + llvmpipe 软件渲染）下运行全部 11 项原生测试：6 项无头规则与通关测试、输入流程、动画、界面截图审查、战斗品质均通过。新增的规则测试覆盖燃灯（三名角色）、存档往返、识破、四象分阶和精英词缀。

PR 初始性能测试使用软件渲染，只能作参考：压力场景（170 名敌人、400 发敌弹）平均帧 133 ms，3.0 为 110 ms；绘制调用 421，3.0 为 294。模拟与界面逻辑耗时各约 5 ms。

发布前已完成 Windows 实机的审查修复、十一组原生回归、实体显卡压力测试与独立发行包验证，见 [3.1 Windows 验收记录](NIGHT_CROSSING_3_1_QA.md)。实体手柄和真人数值平衡仍未验收。
