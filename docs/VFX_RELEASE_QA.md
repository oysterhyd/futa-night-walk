# 3.1.1 墨韵光效 · Windows 审查与发行验证

2026-10-16 在 Windows、Godot 4.7.2 stable、NVIDIA GeForce RTX 4060 Laptop GPU 上审查 PR #2。发行版本为 3.1.1，战斗规则、数值和存档格式保持 3.1 的版本。

## 审查修复

- 死亡事件原本用 `kind` 传递怪物类型，但 `RunWorld.emit()` 会把该字段覆盖为事件名 `death`，导致纸人、灯妖、狐与石卫的专属消散分支失效。改为独立的 `enemy_kind` 字段，覆盖普通死亡和首领清场两条路径，并验证实际灯妖火焰、石卫碎石粒子确实生成。
- 精灵着色器重复乘入纹理颜色及透明度。改为从顶点阶段传递原始调制颜色，片元阶段只采样并应用一次纹理。真实 MultiMesh 渲染的半透明色块从错误的 `(0.1725, 0.1176, 0.0706)` 修正为 `(0.4078, 0.3176, 0.2196)`，与普通精灵参考一致。该行为也符合 [Godot CanvasItem 着色器文档](https://docs.godotengine.org/en/4.5/tutorials/shaders/shader_reference/canvas_item_shader.html#color-and-texture)。
- 初次修复后压力测试第一章 P95 为 17.39 毫秒，超过 16.67 毫秒阈值。限制密集弹幕额外装饰为最多 128 份光晕、64 份光带；基础敌弹和危险轨迹仍由原批次完整绘制。新增检查确认粒子开关两种状态下，400 枚敌弹和 400 条危险轨迹均完整保留。
- 特效图库工具改为由固定时钟独立推进，并屏蔽桌面失焦和输入造成的暂停菜单遮挡。每层六批、两层最多十二批的说明已同步修正。
