# 四章动作版重构与体验打磨

目标：完成灯市旧巷、白狐渡、沉钟寺、无明塔的连续冒险，保留现有印画美术与单装备、单主动技能规则。不能以章节换名、换背景或仅通过自动化检查代替完成。

## 必须完成的内容

1. 四章贯通，装备、技能、符印、遗物和属性跨章保留。每章有独立房间名称、场景、环境规则、敌群和首领打法，最终章后才结算胜利。
2. 后三章的探索与构筑继续有意义：获得适配成长、章节战利品和有取舍的选择，不能只堆生命与伤害。
3. 攻击演出与玩法对应：区分六件装备和六种技能；敌人有可读的起手、轨迹与命中反馈。敌箭与玩家弹道使用不同轮廓，粒子关闭时仍清楚可辨。
4. 门名绑定真实门框，显示实际目的地；靠近后再说明交互、收益与返回状态。当前房间与下一房间不能混淆。大房间、镜头和地图也需核对。
5. 排查碰撞、门、操作缓冲、暂停恢复、跨章存档、重复结算、音频、字体、卡片排版和性能。游戏文案遵守 TEXT_STYLE_GUIDE.md。
6. 多轮优化：先做玩法与辨识，再看实际运行截图和完整通关，修正问题后重复相关检查。交付更新后的 Windows 包、游玩说明和覆盖四章的验收证据。
